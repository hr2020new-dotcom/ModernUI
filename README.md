# 🌐 ModernUI

> A modern, clean, and responsive landing page built with HTML5 and CSS3.

ModernUI is a modern front-end website designed to demonstrate clean UI design, responsive layouts, and fundamental front-end development concepts using pure HTML and CSS.

---

## 📸 Preview

![ModernUI Preview](./preview.png)

---

## ✨ Features

- 🎨 Modern and clean user interface
- 📱 Responsive design for different screen sizes
- 🖥️ Desktop, tablet, and mobile friendly
- 🌈 Modern gradient hero section
- 🧭 Simple and clean navigation bar
- 🔘 Interactive call-to-action button
- ⚡ Lightweight and fast
- 🧹 Clean and organized HTML & CSS
- ♿ Simple and accessible structure

---

## 🛠️ Built With

This project was built using:

- **HTML5** — Website structure and semantic elements
- **CSS3** — Styling, layout, colors, spacing, and responsive design

No frameworks or libraries were used.
